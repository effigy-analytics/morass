# Adopting Morass 0.8 structural material fixtures

Morass 0.8 is an additive release. Existing 0.7 components, material utility
classes, and theme tokens remain available. The release adds four structural
primitives:

- `Fixture` frames durable focal content with a tokenized metal edge and inset
  surface.
- `Plaque` provides a compact engraved label for a fixture, section, or durable
  status.
- `Medallion` provides a struck-metal marker for ranks, milestones, and
  ceremony identity in gold, silver, or bronze.
- `Rail` provides a joined material divider with an optional consumer-owned
  semantic label.

```tsx
import { Fixture, Medallion, Plaque, Rail } from "@effigy-analytics/morass";

<Fixture trim={<Plaque>Official ballot</Plaque>}>
  <h1>2026 television awards</h1>
</Fixture>;

<Rail label={<h2>Categories</h2>} />;

<Medallion aria-label="First place" finish="gold" size="sm">
  1
</Medallion>;
```

Use fixtures to establish hierarchy, not to frame every card. A fixture is most
effective around one page-defining object such as a ballot, ceremony summary,
scoreboard, or operator console. Keep dense controls and ordinary reading
surfaces on their existing Morass primitives.

An unlabeled `Rail` is decorative and hidden from assistive technology. When a
rail introduces content, pass the existing semantic heading through `label`;
do not duplicate that heading elsewhere for visual effect.

The structural material colors are public theme tokens:

- `--m-fixture-metal`
- `--m-fixture-metal-highlight`
- `--m-fixture-metal-shadow`
- `--m-fixture-inset`
- `--m-fixture-inset-on`
- `--m-fixture-patina`
- `--m-medallion-{gold,silver,bronze}`
- `--m-medallion-{gold,silver,bronze}-{highlight,shadow,on}`

Explicit light, explicit dark, and OS-selected themes include complete values.
`--m-fixture-inset-on` against `--m-fixture-inset` is part of the Morass
contrast contract. Forced-colors mode removes decorative gradients and shadows
while retaining visible boundaries.
