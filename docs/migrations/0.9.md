# Adopting Morass 0.9 Studio Workbench

Morass 0.9 is additive. Existing 0.8 components, structural fixtures, material
utilities, and theme tokens remain available. Existing component defaults do
not change.

The release adds the opt-in Studio Workbench CSS vocabulary for workbench,
sheet, index-card, highlighter, tape, felt-action, and binder-tab compositions.
It also exports the typed `STUDIO_TREATMENTS` role map. See the
[Studio Workbench CSS contract](../studio-workbench.md) for every supported
selector, token, treatment role, and accessibility boundary.

Import the existing stylesheet and opt specific product regions into its public
classes:

```tsx
<main className="m-workbench">
  <article className="m-sheet m-sheet--edge-1">
    <h1>
      Make your{" "}
      <span className="m-highlight m-highlight--rose">prediction</span>
    </h1>
  </article>
</main>
```

Binder tabs are CSS primitives rather than a replacement for semantic
controls. Keep route navigation as links and form steps as buttons. Use
`Tabs` only for a real tablist/tab-panel relationship.

The release adds these public theme tokens:

- `--m-workbench-bg`, `--m-workbench-on`, `--m-workbench-grid`
- `--m-sheet-bg`, `--m-sheet-on`, `--m-sheet-border`, `--m-sheet-shadow`
- `--m-index-card-bg`, `--m-index-card-line`
- `--m-highlight-{sage,rose,butter,sky,lavender}`
- `--m-binder-tab-accent`
- `--m-attachment-tape`
- `--m-felt-action`, `--m-felt-action-strong`, `--m-felt-action-on`

Explicit light, explicit dark, and OS-selected themes include complete values.
Studio Workbench text combinations join the Morass contrast contract.
Forced-colors mode removes decorative highlighter and tape treatments while
retaining visible boundaries, focus, and binder-tab state.
